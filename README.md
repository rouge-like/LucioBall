# LucioBall# LucioBall

## C++ 코드 요약

**핵심 게임 로직:**
*   **`LucioBall.cpp`**: 언리얼 엔진 프로젝트의 주요 모듈 정의입니다.
*   **`BouncyBall.cpp`**: 튕기는 공의 물리, 움직임, 충돌 감지, 반사, 마찰 및 캐릭터와의 상호
작용을 구현합니다. 또한 항상 카메라를 향하는 시각적 회전 및 위젯을 처리합니다.
*   **`GoalPost.cpp`**: 골대를 정의하고, 공 충돌, 득점 로직(플레이어 대 AI, 자책골)을
처리하며, 페이딩 애니메이션과 함께 "GOL!" 텍스트를 표시합니다.
*   **`JumpPoint.cpp`**: 점프 포인트를 나타내는 간단한 액터로, 주로 충돌 감지 및 태그 지정에
사용됩니다.
*   **`LucioBallMode.cpp`**: 튕기는 공 생성, 게임 시간 관리, 게임 종료 조건(슬로우 모션, 레벨
전환) 처리, 게임 UI(점수, 타이머, 스킬, 궁극기 게이지) 업데이트를 담당하는 핵심 게임
모드입니다.
*   **`LobbyGameMode.cpp`**: 로비의 입력 모드를 설정하여 마우스 커서를 표시하고 UI 전용
입력을 설정합니다.
*   **`VelCharacter.cpp`**: 이전 프레임의 속도를 저장하는 기본 캐릭터 클래스로, 움직임 예측
또는 특정 물리 상호 작용에 사용될 수 있습니다.

**AI 로직 (CEJ/Ai):**
*   **`AiLucio.cpp`**: 루시우 캐릭터의 AI를 구현합니다. 점프 포인트 찾기, 점프, 벽 타기,
낙하, 공 차기 등 다양한 상태를 처리합니다. 경로 찾기, 벽 추적, 공 접근 및 차기 방향 계산을
사용합니다. 또한 유휴 및 이동 상태에 대한 애니메이션을 관리합니다.
*   **`AiWallRunning.cpp`**: AI 캐릭터를 위한 벽 타기 메커니즘을 제공합니다. 벽 감지, 벽 타기
시작 및 중지, 벽에 붙는 힘 적용, 벽 타기 중 움직임 관리 로직이 포함됩니다. 또한 점프 포인트
감지 및 자동 점프를 처리합니다.

**UI 로직 (OSC/UI):**
*   **`GameHUD.cpp`**: `GameUIWidget`을 생성하고 뷰포트에 추가하는 역할을 하는 게임의 주요
HUD입니다.
*   **`GameUIWidget.cpp`**: 플레이어/상대 점수, 게임 타이머, 골 텍스트, 스킬 쿨다운, 궁극기
게이지와 같은 다른 UI 요소를 관리하고 업데이트하는 중앙 위젯입니다.
*   **`GoalTextWidget.cpp`**: "Goal!" 또는 "OwnGoal!" 텍스트를 애니메이션과 함께 표시한 후
일정 시간 후에 숨깁니다.
*   **`LobbyHUD.cpp`**: `LobbyUIWidget`을 생성하고 뷰포트에 추가하는 역할을 하는 로비의
HUD입니다.
*   **`LobbyTextButtonWidget.cpp`**: 텍스트가 있는 재사용 가능한 버튼 위젯으로, 마우스 진입
및 클릭 애니메이션을 처리하고 클릭 이벤트를 브로드캐스트합니다.
*   **`LobbyUIWidget.cpp`**: 로비를 위한 기본 UI 위젯입니다.
*   **`ScoreWidget.cpp`**: 플레이어와 상대방의 점수를 표시하고 업데이트합니다.
*   **`SkillWidget.cpp`**: 동적 머티리얼 인스턴스를 사용하여 스킬의 시각적 진행/쿨다운을
관리합니다.
*   **`TimerWidget.cpp`**: 남은 게임 시간을 "분:초" 형식으로 표시합니다.
*   **`UltGaugeWidget.cpp`**: 동적 머티리얼 인스턴스와 백분율 텍스트를 사용하여 궁극기 능력의
충전 진행 상황을 관리하고 표시합니다.
